# Producer

Producer is an AI assistant that helps streamers make a better live show, with private director's notes for the presenter and relevant questions, facts, and visuals for viewers.

Built with OpenAI Codex for the Codex x TwitchCon Hackathon.

Implementation and setup instructions will be added before the competition submission. This repository currently contains only this README and the MIT license.
