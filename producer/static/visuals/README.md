# Bundled visual

`canada.svg` is a generalized outline derived from Natural Earth's 1:110 million
Admin0 countries v5.1.1. It shows no streets, cities or province boundaries.
Natural Earth places its map data in the public domain; the rendered SVG retains
a visible source credit and contains no scripts or external references.

- [Dataset](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/)
- [Terms](https://www.naturalearthdata.com/about/terms-of-use/)

The helper serves this specific file, not arbitrary remote map URLs. The active
passive producer can also use explicitly supplied local show-folder images;
spoken-command map control is historical and is not an active product feature.
